# 🩺 HealthFlow AI

AI-powered healthcare workflow assistant.

## Features

- Patient query analysis
- Priority classification
- Department recommendation
- Dashboard history
- REST API integration


## Tech Stack

Frontend:
React.js

Backend:
FastAPI

Database:
SQLite

AI:
Python based NLP logic


## Architecture

React
↓
FastAPI
↓
AI Service
↓
SQLite Database


## How to run

Backend:

cd backend

python -m uvicorn main:app --reload


Frontend:

cd frontend

npm run dev
